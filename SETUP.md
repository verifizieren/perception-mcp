# SETUP — Perception RE MCP (token-optimized fork)

Follow top to bottom. Don't skip. Takes ~3 min.

---

## What you need first

- **Node.js v18+** — check: `node -v`. No version printed? Install from https://nodejs.org
- **Perception.cx** open, with the AngelScript IDE
- **Claude Code** CLI installed

---

## Step 1 — Put the folder somewhere permanent

Unzip `perception-mcp.zip`. Move the `perception-mcp` folder to a spot you won't delete
(e.g. `C:\tools\perception-mcp` or `~/tools/perception-mcp`).

If replacing an old install: **delete the old folder first**, drop this one in the same place
with the same name, so your existing `~/.mcp.json` path still points at it.

---

## Step 2 — Build it

Open a terminal **inside the folder**:

```bash
cd path/to/perception-mcp
npm install
npm run build
```

This creates `dist/index.js`. If `dist/` doesn't appear, the build failed — read the error,
you probably don't have Node.

---

## Step 3 — Get the full path to dist/index.js

You need the ABSOLUTE path. In the folder run:

- macOS / Linux: `echo "$(pwd)/dist/index.js"`
- Windows (PowerShell): `Resolve-Path dist\index.js`

Copy what it prints. Use **forward slashes** even on Windows
(e.g. `C:/tools/perception-mcp/dist/index.js`).

---

## Step 4 — Register with Claude Code

Edit `~/.mcp.json` (create it if missing). Paste, swapping in your path from Step 3:

```json
{
  "mcpServers": {
    "perception-re": {
      "command": "node",
      "args": ["<PASTE-YOUR-PATH>/dist/index.js"]
    }
  }
}
```

Windows path example: `"C:/tools/perception-mcp/dist/index.js"`

---

## Step 5 — Load the AngelScript server in Perception

1. Open Perception → AngelScript IDE / script editor
2. Open `re_server.as` (in the folder)
3. Run it

Console shows:
```
[RE Server] Waiting for MCP server... (attempt 1)
```
That's correct — it waits for Claude Code. Leave it running.

---

## Step 6 — Start Claude Code

Open Claude Code in any project. It auto-starts the MCP from `~/.mcp.json`.
The Perception console flips to:
```
[RE Server] Connected to MCP server.
```

Now the 9 RE tools are live.

---

## Step 7 — Smoke test

In Claude Code, ask it to run:

```
re_proc op:attach name:"cs2.exe"
re_proc op:info
```

Get PID + base back = working. Done.

---

## If it breaks

| Symptom | Fix |
|---|---|
| MCP not in Claude Code | Wrong path in `~/.mcp.json`. Fix it, restart Claude Code. |
| `dist/index.js` missing | You skipped `npm run build`, or no Node. |
| AS stuck "Waiting for MCP server..." | Normal until Claude Code starts. Not an error. |
| `re_server.as` throws on load | Perception AngelScript API mismatch — report the console line. |
| Port 9001 in use | Something's holding it. Kill the stale node process. |
| 2nd Claude Code instance no tools | Relay retries every 3s; first instance (hub) must stay open. |

---

## Notes

- `dist/` is regenerated by `npm run build` — never ship it, never edit it.
- Only edit `src/index.ts` (dispatchers) or `re_server.as` (RE commands), then rebuild.
- Full tool/op reference + optimization changelog is in `README.md`.
